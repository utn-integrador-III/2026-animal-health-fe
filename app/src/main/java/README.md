# FrontEnd - Animal Health Platform

Android mobile application for managing veterinary records.

## Technology
- Kotlin
- Jetpack Compose

## Libraries
- Retrofit - Connect the app with the API
- Jetpack Compose - Build the screens
- Hilt - Dependency injection
- ViewModel - Manage the state of the screens
- Coil - Load images
- DataStore - Save the login token locally
- Compose Material 3 - Create the graphical interface (buttons, forms, cards, menus, tables, etc.) following Google's modern design
- Navigation Compose - Navigate between screens
- Gson - Convert Kotlin objects to JSON and vice versa
